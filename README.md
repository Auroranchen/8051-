# 8051 八位数字时钟

基于 **AT89C52 单片机**的八位数码管数字时钟课程设计项目，使用 Keil C51 编写，配套 Proteus ISIS 仿真工程，适合学习 8051 单片机定时器、数码管动态扫描、按键处理及基础嵌入式开发。

## ✨ 项目功能

- **时间显示**：八位数码管显示时、分、秒，格式为 `HH-MM-SS`。
- **时间设置**：支持调整小时、分钟和秒。
- **三组闹钟**：支持设置三组闹钟时间，通过蜂鸣器进行提醒。
- **整点预提醒**：每小时最后十秒提供预提醒逻辑。
- **倒计时**：支持 60 秒倒计时。
- **动态扫描**：使用 Timer0 中断实现数码管动态显示。
- **按键控制**：支持设置项目切换、数值增减、退出设置及启动倒计时。
- **仿真支持**：提供 Proteus 电路文件，可用于仿真学习。

## 🔌 硬件与引脚说明

| 单片机引脚 | 功能 |
|---|---|
| P0 | 数码管段码数据总线 |
| P2.0 | 段码锁存控制 LE1 |
| P2.1 | 位选锁存控制 LE2 |
| P1.0 | SB1：切换设置项目 |
| P1.1 | SB2：当前设置项加一 |
| P1.2 | SB3：当前设置项减一 |
| P1.3 | SB4：退出设置 |
| P1.4 | SB5：启动 60 秒倒计时 |
| P3.2 | 蜂鸣器控制 BUZ |

硬件电路还包含晶振、复位电路、电阻、电容及其他外围器件。具体连接请以 Proteus 原理图为准。

## 🎮 按键操作

| 按键 | 功能 |
|---|---|
| SB1 | 循环切换时间和闹钟设置项目 |
| SB2 | 当前设置项加一 |
| SB3 | 当前设置项减一 |
| SB4 | 退出设置，返回正常显示 |
| SB5 | 启动 60 秒倒计时 |

时间设置范围：小时 `0–23`，分钟和秒 `0–59`。按键程序包含约 10 ms 消抖处理，并等待按键释放。

## 🚀 运行方法

### 1. 使用 Keil 编译

1. 安装 Keil uVision 5 及 C51 工具链。
2. 打开 `程序/程序.uvproj`。
3. 检查目标芯片型号及晶振频率配置。
4. 执行 `Build` 或 `Rebuild Target 1`。
5. 编译成功后生成 HEX 固件文件。

### 2. 使用 Proteus 仿真

1. 使用 Proteus ISIS 打开 `仿真.DSN`。
2. 检查单片机型号、时钟频率及程序文件路径。
3. 如有需要，重新指定编译生成的 HEX 文件。
4. 启动仿真，测试数码管显示、按键操作、闹钟和倒计时功能。

## ⚠️ 已知问题

- Timer0 定时参数可能存在偏差，需要重新计算并校准。
- Keil 工程与 Proteus 仿真文件的晶振频率配置存在差异，需检查后再运行。
- 时间及闹钟参数保存在 RAM 中，断电后不会保留。
- 倒计时固定为 60 秒，暂不支持自定义、暂停或取消。
- 闹钟暂不支持独立启用、禁用及消音设置。
